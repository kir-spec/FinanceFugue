## 1. Установка

### Windows (рекомендуется для большинства пользователей)

1. Скачайте `FinanceFugue-1.0.0.exe` со страницы Releases.
2. Запустите установщик — Portable EXE, не требует установки.
3. (Опционально) Создайте ярлык на рабочем столе.

> Требования: Windows 10+ (x64). EXE portable — никаких зависимостей не нужно.

### Из исходников (для разработчиков / Linux / macOS)

```bash
git clone https://github.com/your-repo/financefugue.git
cd financefugue

python -m venv .venv
source .venv/bin/activate   # или .venv\Scripts\Activate.ps1 на Windows

pip install -r requirements.txt
python main_pyside.py
```

> Требования: Python 3.11+, PySide6 6.10+.

## 2. Первый запуск

1. **EULA** — при первом запуске показывается лицензионное соглашение. Примите его
   (кнопка "Принимаю").
2. **First-run wizard** — если нет ранее сохранённой БД, появится помощник.
   Укажите папку для хранения базы данных (по умолчанию — `%LOCALAPPDATA%\FinanceFugue`).
3. Выберите режим хранения файлов:
   - **Скопировать в базу** — все прикреплённые файлы будут храниться рядом
     с базой данных. Безопасно при переносе БД.
   - **Оставить как есть** (только ссылки) — файлы остаются на исходном месте,
     база хранит только пути. Экономит место, но при перемещении файлов
     ссылки ломаются.

Позже режим можно изменить: **Настройки → База данных**.

## 3. Интерфейс

Главное окно состоит из трёх областей:

```
┌─────────────────┬────────────────────────────────────┐
│  👤 КЛИЕНТЫ     │  ДАШБОРД (В работе / Долги / ...)  │
│                 ├────────────────────────────────────┤
│  [🔍 Поиск]     │                                    │
│  [Сортировка]   │  ПРОФИЛЬ КЛИЕНТА                    │
│                 │  Имя клиента                        │
│  Список         │  [+ добавить заказ] [⚙ настройки]  │
│  клиентов       │  ━━━━━━━━━━━━━━━━━━━━━━━━━━━       │
│                 │  📊 СТАТИСТИКА                      │
│  [+ Новый]      │  ━━━━━━━━━━━━━━━━━━━━━━━━━━━       │
│  [📁 Файлы]     │  📋 ЗАКАЗЫ                          │
│  [⚙ Настройки]  │  Заказ 1 ... Заказ N                │
└─────────────────┴────────────────────────────────────┘
                  [💾 Сохранено]   status bar
```

### Боковая панель

- **Поиск** — фильтрует список клиентов по имени, email или соц.сети (с задержкой 200мс).
- **Сортировка** — по имени (А-Я / Я-А), по дате заказа (новые/старые), по срочности.
- **Список клиентов** — drag-and-drop папки клиентов прямо в список для импорта.
- **Менеджер файлов** (📁) — глобальное дерево клиент/заказ/файл с drag-and-drop.

### Профиль клиента

- Кнопка **⚙ настройки** — переименование, контакты, заметки, удаление.
- Кнопка **📝 заметка** (✏️) — сворачиваемая панель для длинных заметок.
- Поле **Долг** — кликабельно, открывает историю платежей.
- Карточка каждого заказа:
  - **Стоимость**, **Аванс**, **Долг** — кликабельные поля.
  - **📅 Дедлайн** — становится оранжевым за 5 дней, красным за 3 дня.
  - **Файлы** — drag-and-drop или кнопка. Двойной клик — открыть файл.
  - **Платежи** — кнопка открывает диалог с историей (добавление/возврат/удаление).

### Дашборд

5 индикаторов сверху окна:
- 📋 **В работе** — заказы в статусе «В работе».
- ✅ **Выполнено** — заказы в статусе «Завершён».
- 💰 **Авансы** — сумма всех авансов (мультивалютно: «1 000 ₽ + 50 $»).
- 💳 **Долги** — неоплаченный остаток (красный, если > 0).
- 💵 **КАССА ✏️** — интерактивная касса (все полученные платежи).
  - **Клик по плашке Кассы** открывает диалог ручной корректировки (`CashAdjustmentDialog`):
    - Установка точного остатка кассы (автоматический расчет дельты +/-);
    - Внесение / списание средств с указанием причины;
    - Фиксация в истории операций со специальным типом `«корректировка»`.

### Строка состояния

- **Сохранено** — последний статус авто-сохранения.
- **⚠ Дедлайны** — уведомления о приближающихся дедлайнах (каждые 30 минут).

## 4. Типовые сценарии

### 4.1 Создать нового клиента

1. Нажмите **➕ Новый клиент** в боковой панели или `Ctrl+N`.
2. Введите имя.
3. Клиент появится в списке; его имя подсветится.

Клиенты **без заказов** помечаются значком 📋 и работают нормально.

### 4.2 Создать заказ

1. Откройте профиль клиента.
2. Нажмите **➕ добавить заказ**.
3. Заполните:
   - **Тип услуги** — название (например, "Монтаж звука").
   - **Стоимость** — общая цена в выбранной валюте.
   - **Аванс** (опционально) — предоплата.
   - **Дедлайн** — дата завершения.
4. Подтвердите.

### 4.3 Добавить платёж

1. В карточке заказа нажмите кнопку **+ платёж**.
2. Выберите тип (платёж / аванс / корректировка), сумму, дату, примечание.
3. Подтвердите.

> Все суммы валидируются: отрицательные = возвраты; не больше долга; не NaN/Inf.

### 4.4 Интеллектуальное удаление (Выбор судьбы финансов)

При отправке клиента или заказа в корзину программа проверяет наличие платежей:
- Если оплат не было — объект сразу перемещается в корзину.
- Если оплаты были внесены — программа открывает диалог выбора:
  1. **«💵 Сохранить деньги в кассе»** — заказ удалится, но полученные деньги останутся в общем балансе кассы как зафиксированный доход (в служебной записи «🏛 Корректировки кассы»);
  2. **«🗑 Списать и убрать из кассы»** — платежи аннулируются, касса уменьшится на сумму заказа.

### 4.5 Прикрепить файлы

Способы:
- **Drag-and-drop** в карточку заказа.
- **➕ добавить файл** → выбрать через диалог.

Режим хранения (копировать/ссылки) определяется в Настройках. Кнопка «Открыть» — открывает в системном приложении.

### 4.6 Холодный архив заказов (🗄)

Завершенные проекты можно отправить в «Архив». Они исчезнут из активного профиля клиента, но будут доступны для просмотра и аналитики через кнопку **«🗄 Архив»** с удобной группировкой по годам и месяцам.

### 4.7 Двусторонняя синхронизация с Telegram-ботом

1. В боте `@FinanceFugue_bot` выполните команду `/sync` и скопируйте свой Chat ID.
2. В программе откройте вкладку **Настройки → Синхронизация** (или кнопку «📱 Бот»).
3. Вставьте Chat ID и нажмите «Проверить связь».
4. Включите **«Автосинхронизация при сохранении»** — база будет автоматически обновляться в Telegram без дубликатов и спама (старые файлы автосинхронизации автоматически удаляются).

## 5. Бэкапы и перенос данных

### Автоматические бэкапы настроек

Каждое закрытие приложения создаёт бэкап `crm_settings_*.json` в папке
`settings_backups/`. Хранятся последние 5 бэкапов.

### Ручной бэкап базы

**Настройки → Создать копию настроек** + **Полный бэкап (ZIP)** —
восстановление после любого сбоя.

### Восстановление из бэкапа

1. Закройте приложение.
2. Замените `pro_database.json` на сохранённую копию.
3. Запустите приложение.

Файлы прикреплённые к заказам **не включены** в JSON-бэкап — только полный
ZIP-бэкап содержит файлы.

## 6. Где хранятся данные

```
%LOCALAPPDATA%\FinanceFugue\         # Windows
~/.local/share/FinanceFugue/         # Linux
~/Library/Application Support/       # macOS
│
├── pro_database.json          ← все клиенты / заказы / платежи
├── crm_settings.json          ← настройки
├── attached_files/            ← файлы клиентов (если выбран copy-режим)
│   └── <order_id>/<file>
├── settings_backups/          ← авто-бэкапы настроек (последние 5)
└── logs/                      ← crm_YYYY-MM-DD.log (ротация 2 МБ x 5)
```

На **macOS/Linux** путь может быть `Path("pro_database.json")` (рядом с EXE), если приложение запущено из source-tree.

## 7. Решение проблем

### «Другой экземпляр FinanceFugue уже использует эту базу»

Две копии программы запущены с одной БД. Закройте одну из них.

Если уверены что других копий нет — удалите файл `<db>.json.lock` рядом с `pro_database.json`.

### «Не удалось загрузить базу данных»

Файл `pro_database.json` повреждён. Варианты:
1. Восстановить из бэкапа (см. раздел 5).
2. Открыть вручную и проверить JSON (например, [jsonlint.com](https://jsonlint.com)).
3. Создать новую базу (данные теряются, настройки остаются).

### Долг показывает NaN или Inf

Не должно происходить (валидация при парсинге), но если из старой версии
импортирована повреждённая БД — будет заменено на 0. Проверьте файл.

### Прикреплённый файл «не найден»

Режим хранения «только ссылки»: файл был перемещён или удалён с диска.
- Найти файл и положить обратно.
- Или удалить запись о файле из заказа.

### Уведомления о дедлайнах не появляются

- Проверьте **Настройки → Уведомления о приближающихся дедлайнах** (должно быть включено).
- Уведомления показываются только для **новых** алертов после предыдущего подтверждения.
- Если все просроченные давно подтверждены — popup не появится (только статус-бар).

## 8. Безопасность и приватность

FinanceFugue хранит все данные **локально** на вашем компьютере. Никакие
данные не передаются по сети без явного действия пользователя
(импорт из сети, drag-and-drop облачных файлов и т.п.).

- **Шифрование БД на диске** — не предусмотрено. Рекомендуется
  использовать BitLocker (Windows) / FileVault (macOS) / LUKS (Linux).
- **JSON-открытый формат** — резервные копии можно открыть в любом текстовом редакторе.
- **Drag-and-drop файлов** ограничен папкой базы данных (path traversal невозможен).

Подробности: см. `PRIVACY.md`.
