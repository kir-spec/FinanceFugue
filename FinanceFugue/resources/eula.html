1. Предмет соглашения

1.1. Разработчик предоставляет неисключительную лицензию на программу FinanceFugue («Программа»).

1.2. Программа — локальная настольная CRM для учёта клиентов, заказов, платежей и прикреплённых файлов на одном устройстве Пользователя.

1.3. Программа поставляется в виде исполняемого файла без отдельной установки среды выполнения (Python упакован в дистрибутив).

1.4. Территория использования — весь мир.

2. Локальная архитектура

2.1. Программа полностью локальна. Все операции — учёт клиентов, расчёт платежей, drag-and-drop файлов, бэкапы, диагностика — выполняются только на устройстве Пользователя. Сторонних онлайн-сервисов, кроме явно указанных, Программа не использует.

2.2. Никакой аналитики, рекламы или обновления данных через внешние серверы не выполняется автоматически.

2.3. Учётные записи, регистрация, отправка идентификаторов Пользователя на серверы Разработчика — отсутствуют. Программа работает без сервера лицензий.

2.4. Изменения в ОС (Windows Update, политика Защитника Windows, прекращение поддержки Windows 10 после 14.10.2025) не являются основанием для возврата средств или претензий.

3. Лицензия, демо-режим и устройства

3.1. Лицензия приобретается разовой оплатой; ключ доставляется на e-mail или иным согласованным способом после оплаты.

3.2. Демо-режим: бесплатный полнофункциональный доступ без ограничения срока для оценки функционала до покупки.

3.3. Лицензия: бессрочная (без ограничения срока), действует на 1 (одно) устройство Пользователя. Привязка по идентификатору оборудования (HWID).

5. Данные, конфиденциальность и диагностика

5.1. Локальное хранение: данные клиентов хранятся на устройстве Пользователя. Разработчик не получает содержимое при обычной работе.

5.2. Разработчик не ведёт маркетинговый профиль и не продаёт данные третьим лицам.

5.3. Контакт при покупке: e-mail используется только для доставки ключа и переписки по заказу.

5.4. Автоматическая отправка диагностики

5.4.0. По умолчанию — ОТКЛЮЧЕНО. FinanceFugue не отправляет данные автоматически без явных действий Пользователя.

5.4.1. Если Пользователь нажимает «Отправить отчёт об ошибке», Программа создаёт файл logs/crash_<timestamp>.log. Передача файла происходит только по инициативе Пользователя.

5.4.2. Лог содержит: версию, ОС, текст ошибки, stack trace, путь к БД. Разработчик видит только неисправную работу Программы.

5.4.3. Лог не содержит: данные клиентов, платежи, заметки, содержимое файлов, пути вне папки БД.

5.4.4. Никакой телеметрии, фоновых процессов, передающих данные, в Программе нет.

5.5. HWID (идентификатор устройства) — локальный. При установке Программа сохраняет хеш-идентификатор оборудования в crm_settings.json для подсчёта инсталляций. Не передаётся Разработчику автоматически.

5.6. Стороннее ПО: сведения о лицензиях библиотек (PySide6 LGPL v3 и др.) — в диалоге «О программе» вкладка «Сторонние компоненты».

5.7. Персональные данные клиентов: Пользователь — оператор ПДн. Разработчик не получает доступ к ПДн и не выступает оператором, если иное не согласовано договором.

5.8. Удаление данных: Пользователь может удалить данные через функции Программы или вручную (файлы pro_database.json, crm_settings.json, папка attached_files/).
