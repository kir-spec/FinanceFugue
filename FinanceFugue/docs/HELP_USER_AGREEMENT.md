между правообладателем (KVF SOFT, ИП Фандеев К.В.) и пользователем
(физическим или юридическим лицом) на использование программы FinanceFugue.

**Дата:** 04 августа 2026 года

## Где его видит пользователь

1. **При первом запуске** — модальный диалог `EulaDialog` с HTML-текстом из
   `resources/eula.html`. Кнопка «Принять и продолжить» неактивна до
   тех пор, пока Пользователь не прокрутит текст до конца **И** не
   поставит флажок «Я принимаю условия».

2. **При обновлении редакции** — если `EULA_VERSION` изменился
   (`crm_settings["eula_version"]` сравнивается с константой в `src/__init__.py`),
   диалог показывается **повторно**.

3. **Меню → О программе → Лицензия (EULA)** — можно прочитать текущую
   редакцию в любой момент.

## Адаптация от KoshaDrive

EULA FinanceFugue переиспользует шаблон KoshaDrive (`setup_custom.iss` +
`resources/html/eula.html`), но **существенно проще** по следующим причинам:

| Тема | KoshaDrive | FinanceFugue |
|------|------------|--------------|
| Внешние сервисы | Telegram API (Telethon) | **Никаких** — чисто локальное |
| Учётные записи | Telegram-аккаунт + tg_id | **Никаких** — HWID локально |
| Демо-режим | 14 календарных дней | **Без ограничения срока** |
| Лицензия | bind HWID + облачная БД | **Только local HWID counter** |
| Шифрование | SQLCipher + cloud sync | **Нет** (только локальный JSON) |
| Сетевые уведомления | HWID → сервер для license check | **Никаких** |
| Crash-reports | Автоматические при ошибках | **НЕТ** (только ручной mailto) |
| Диагностика | Telethon-инфраструктура | **НЕТ** инфраструктуры |
| Страны с принудительным правом | Россия, Украина, Беларусь, Казахстан, EU | **Россия (default)**, остальные через императивные нормы |

Шаблон KoshaDrive HTML сохранён с плейсхолдерами `{{REVISION}}` и `{{DATE}}`,
но без country-specific injection (см. `src/services/eula_renderer.py`).
Если потребуется — модуль расширяется, как в KoshaDrive.

## Кастомизация для разных стран

Текущая реализация — **минимальная** (RU default + императивное право для
прочих юрисдикций). Для полноценного EU/GDPR-рынка нужно
дополнить `eula_renderer.py` секциями `_RU_CONTRACTOR`, `_EU_CONTRACTOR`,
`{COUNTRY_REFUND_NOTE}` плейсхолдерами.

См. образец: `E:\coding\KoshaDrive\src\koshadrive\gui\dialogs\eula_legal_snippets.py`
и `E:\coding\KoshaDrive\docs\licensing_migration_v3.md`.

## Versioning policy

- **MAJOR** (1.0.0): критические изменения в лицензии / коммерческой модели.
- **MINOR** (1.1.0): добавление функционала, не затрагивающее лицензию.
- **PATCH** (1.0.0 → 1.0.1): bugfixes, не требуют новой редакции EULA.

При смене условий EULA — **новая редакция `FF-EULA-ДД.ММ.ГГГГ-N`** и **повторный
показ** диалога пользователю.

## Разработчику

При правке EULA:

1. **Измените `EULA.md`** (markdown-источник для repo).
2. **Измените `resources/eula.html`** (рендерится в диалоге; синхронизируйте разделы).
3. **Измените `EULA_VERSION`** в `src/__init__.py` на новую редакцию.
4. **Добавьте секцию в `CHANGELOG.md`** («Правовая часть») с описанием.
5. **При необходимости — обновите `docs/LEGAL_CHECKLIST.md`** (юр. трассировка).

Пример того, что должно попадать в новую редакцию:
- Изменение коммерческой модели (demo → paid, paid → subscription).
- Добавление / удаление интеграций (например, добавили облако → EULA §2 и §5 меняются).
- Изменение мер шифрования / удаления данных.

**Не требует** новой редакции:
- Bugfixes и refactoring безопасности.
- Добавление функционала без новых внешних сервисов.
- Обновление библиотек в рамках совместимости LGPL.
