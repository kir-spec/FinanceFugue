FinanceFugue

Профессиональная система управления заказами для музыкальных студий, звукорежиссеров и творческих команд.

Программа позволяет вести базу клиентов, отслеживать платежи, управлять сроками выполнения работ и хранить все связанные файлы в одном месте.

Основные возможности:

  • Учет клиентов и полная история их заказов.
  • Автоматический расчет долгов, авансов и общей кассы.
  • Умный менеджер файлов с поддержкой Drag & Drop.
  • Уведомления о приближающихся и просроченных дедлайнах при запуске программы.
  • Локальное хранение данных на вашем компьютере с резервным копированием (JSON и ZIP).

Управление клиентами

Клиенты — основа вашей базы данных. Вся работа строится вокруг карточек клиентов, к которым привязываются заказы и платежи.

Способы создания клиентов:

  • Вручную: Нажмите кнопку '➕ Новый клиент' на левой панели или используйте горячую клавишу Ctrl+N. Введите имя, и клиент сразу появится в списке.
  • Автоматически из папки: Просто перетащите папку с именем клиента из вашего проводника в левую панель со списком клиентов. Программа сама предложит создать клиента с таким именем и импортировать содержимое папки как заказы. Это самый быстрый способ начать работу с существующими архивами.

Взаимодействие со списком:

Выбор клиента: Нажмите на имя клиента, чтобы открыть его профиль в правой части окна. Там отобразится вся информация: статистика, заказы, заметки.

Поиск: Используйте поле "Поиск..." над списком, чтобы мгновенно отфильтровать клиентов по имени. Это удобно, когда база становится большой.

Контекстное меню: Нажмите правой кнопкой мыши на клиенте, чтобы получить доступ к быстрым действиям:

  • Добавить заказ: Мгновенное создание нового заказа для этого клиента.
  • Настройки клиента: Редактирование имени, добавление контактных данных (Email, Telegram, VK) и заметок.
  • Экспорт всех файлов (ZIP): Экспорт всех файлов клиента в ZIP-архив.
  • Удаление: Удаление клиента и всех связанных с ним данных.

Сортировка: Используйте выпадающий список под кнопками или контекстное меню (ПКМ на пустом месте списка) — по имени, дате заказов или срочности дедлайна.

Карточки заказов

Карточка заказа — это центральный элемент для отслеживания конкретной работы. Здесь собрана вся финансовая и файловая информация по задаче.

Создание и редактирование

  • Создание заказа: Откройте профиль клиента и нажмите большую зеленую кнопку '➕ добавить заказ'. Заполните поля и нажмите "Создать".
  • Редактирование: Большинство параметров заказа (стоимость, аванс, дата заказа и срок выполнения) можно изменить прямо в его карточке, кликнув на соответствующее поле.
  • Дополнительные действия: Нажмите на иконку шестеренки (⚙️), чтобы получить доступ к дополнительным функциям:
    • Изменить название услуги
    • Копировать ID заказа
    • Экспортировать файлы в ZIP-архив
    • Дублировать заказ
    • Удалить заказ

Работа со статусами и сроками

  • Статус выполнения: Статус заказа ('В работе' / 'Завершен') меняется с помощью большого переключателя в заголовке карточки. Этот переключатель имеет умную логику:
    • При завершении заказа с долгом, программа предложит автоматически погасить его. Вы можете согласиться, и тогда будет создан платеж на сумму долга. Либо вы можете отказаться, и заказ все равно будет помечен как "Завершен", но долг останется.
    • При возврате заказа в работу, если последний платеж был автоматическим, программа предложит отменить его и вернуть сумму в долг. Это удобно для доработок, когда оплата уже прошла.
  • Дедлайны: Программа визуально помогает отслеживать сроки. Дата дедлайна подсвечивается разными цветами в зависимости от срочности:
    • Зеленый: В запасе больше 5 дней.
    • Желтый: Осталось меньше 5 дней.
    • Красный: Срок истекает через 3 дня или уже прошел.

Финансовый учет

Программа автоматически ведет учет всех финансов по каждому заказу и клиенту, а также отображает общую статистику в дашборде. Все расчеты происходят в реальном времени по формуле: Долг = Стоимость − Сумма всех платежей.

Способы управления финансами:

  • Тумблер статуса ('НЕ ВЫПОЛНЕН' / 'ВЫПОЛНЕН'): Этот переключатель в заголовке карточки заказа напрямую связан с финансами. При переводе заказа в статус 'ВЫПОЛНЕН', если имеется долг, программа предложит автоматически его погасить. И наоборот, при возврате заказа в работу, если последний платеж был автоматическим, система предложит его отменить.
  • Ручное редактирование: Вы можете напрямую изменять значения в полях 'СТОИМОСТЬ', 'АВАНС' и 'ДОЛГ'. Программа обладает умной логикой:
    • При уменьшении стоимости ниже уже оплаченной суммы, программа предложит оформить возврат.
    • При изменении долга, будет автоматически создана "корректировка" для выравнивания баланса.
  • Добавление платежа: Нажмите кнопку '✚ добавить', чтобы открыть диалог внесения платежа. Это основной способ фиксации всех финансовых операций.
  • Быстрая оплата: Используйте кнопку-переключатель '❌ НЕ ОПЛАЧЕНО' / '✅ ОПЛАЧЕНО'. При нажатии на '❌ НЕ ОПЛАЧЕНО' программа предложит автоматически создать платеж на всю сумму долга. При выключении статуса '✅ ОПЛАЧЕНО' программа предложит отменить последнюю транзакцию.

Типы платежей:

При добавлении платежа через диалог (кнопка '✚ добавить') вы можете выбрать его тип:

  1. Платеж: Стандартная оплата за работу. Уменьшает долг.
  2. Аванс: Предоплата. Также уменьшает долг и дополнительно учитывается в общей статистике авансов.
  3. Корректировка: Специальный тип для нетипичных операций. Включает в себя подтипы для точного учета:
    • Возврат средств: Для оформления возврата клиенту (сумма будет отрицательной).
    • Скидка / Списание: Уменьшает долг без изменения общей стоимости заказа (сумма будет положительной).
    • Техническая правка (+/-): Для ручной корректировки баланса в любую сторону.

Вся история платежей по заказу доступна по кнопке '📋 история'. В этом окне можно просмотреть детали каждой транзакции или удалить ее.

Работа с файлами

FinanceFugue предлагает гибкие инструменты для управления файлами проектов.

Режимы хранения:

Способ хранения файлов выбирается при первом запуске программы, но его можно изменить в настройках при переносе базы данных.

  • Ссылки (рекомендуется для начала): Программа просто запоминает путь к вашим файлам. Это экономит место, так как не создаются дубликаты. Минус: если вы переместите или удалите оригинальный файл, программа потеряет к нему доступ.
  • Копии в базе данных: Программа создает копию каждого файла и сохраняет ее в специальной папке рядом с базой данных. Это самый надежный способ, гарантирующий, что файлы никогда не потеряются. Идеально подходит для переноса базы на другой компьютер.

Способы добавления файлов:

  • Перетаскивание (Drag & Drop): Просто перетащите файлы или папки из проводника прямо на карточку заказа.
  • Кнопка "Добавить файлы": Внутри карточки заказа, в разделе файлов, есть кнопка для стандартного диалога выбора файлов.
  • Глобальный менеджер: Откройте его кнопкой '📁 менеджер файлов' на левой панели. Это мощный инструмент, который показывает дерево всех клиентов, заказов и файлов. Вы можете перетаскивать файлы прямо на имя клиента или заказа в этом окне.

Панель статистики (дашборд)

В верхней части окна отображается сводка по всей базе: количество клиентов, общая касса, авансы, долги и завершённые заказы. Данные обновляются автоматически при сохранении.

В профиле клиента отдельно показывается статистика по его заказам: всего, готово, аванс, внесено, долг.

Первый запуск

При первом запуске мастер настройки предложит:

  • Папку для базы данных — где хранить `pro_database.json` (можно выбрать облачную папку).
  • Режим хранения файлов: ссылки на оригиналы или копии в папке базы (`attached_files`).

Перед работой необходимо принять лицензионное соглашение (EULA) и политику конфиденциальности.

Настройки

Кнопка «⚙ Настройки» или Ctrl+Shift+S открывает окно управления:

  • База данных: выбор места хранения, импорт из папки, экспорт/импорт JSON, полный ZIP-бэкап.
  • Опасные операции: удаление всех файлов или полная очистка базы (с подтверждением).
  • Настройки приложения: резервное копирование и восстановление `crm_settings.json`.
  • Уведомления: включение напоминаний о дедлайнах при запуске.
  • Правовая информация: «О программе», EULA, политика конфиденциальности, лицензии PySide6.

Уведомления о дедлайнах

При запуске программа проверяет незавершённые заказы с дедлайном в ближайшие 5 дней (включая просроченные) и показывает сводное окно. Отключить можно в Настройках.

На карточке заказа даты подсвечиваются: зелёный (>5 дней), жёлтый (<5 дней), красный (≤3 дня или просрочено).

Безопасность данных

База данных: Все данные хранятся в одном JSON-файле в открытом виде (без шифрования внутри программы). Формат включает поле schema_version для совместимости при обновлениях. Одновременно может работать только один экземпляр программы с одной базой. Вы можете изменить его расположение в настройках (например, перенести в облачную папку Dropbox/Google Drive для синхронизации). Для защиты диска рекомендуется шифрование Windows (BitLocker) и регулярные резервные копии.

Резервные копии:

  • JSON Экспорт: Только база данных (клиенты, заказы, платежи).
  • Полный ZIP бэкап: База данных + ВСЕ прикрепленные файлы в одном архиве.

Программа автоматически делает бэкапы файлов конфигурации при каждом выходе.

💡 Полезные советы

  • Drag & Drop — ваш лучший друг. Вы можете перетаскивать не только файлы в карточку заказа, но и целые папки в список клиентов для автоматического создания и импорта. Это экономит массу времени.
  • Используйте облачные папки для базы данных. При первом запуске или в настройках укажите папку, которая синхронизируется с облаком (Google Drive, Dropbox, Яндекс.Диск). Так вы получите доступ к своей базе с разных компьютеров и защитите данные от потери.
  • Сортировка по дедлайнам. Нажмите правой кнопкой мыши на списке клиентов и выберите "Сортировка" -> "Срочные". Так вы всегда будете видеть, какие заказы требуют внимания в первую очередь.
  • Уникальный ID заказа. Хотя ID может показаться технической информацией, его удобно использовать в названиях файлов или папок при экспорте, чтобы точно знать, к какому заказу они относятся, особенно если у вас много однотипных проектов.
  • Двойной клик в менеджере файлов. В глобальном менеджере файлов (кнопка на главной панели) вы можете дважды щелкнуть по любому файлу или папке, чтобы мгновенно открыть их в вашей операционной системе.
  • Заметки к клиенту. В настройках клиента есть поле "Заметка". Используйте его для важной информации, которая не относится к конкретному заказу: общие предпочтения клиента, история сотрудничества, важные напоминания.
