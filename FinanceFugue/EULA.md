## 2. Отказ от облачных функций

2.1. **Программа полностью локальна.** Все операции — учёт клиентов,
расчёт платежей, drag-and-drop файлов, бэкапы, диагностика — выполняются
исключительно на устройстве Пользователя. Сторонних онлайн-сервисов,
кроме явно указанных ниже, Программа **не использует**.

2.2. **Никаких сетевых интеграций без явного действия Пользователя.**
Никакая аналитика, реклама или обновление данных через внешние серверы
не выполняются автоматически. Пользователь сам решает, в какую папку
разместить базу данных (это может быть облачная папка вроде Dropbox,
но это действие Пользователя, не Программы).

2.3. **Отсутствие зависимости от сторонней инфраструктуры.** В отличие от
online-only продуктов, Программа сохраняет полную работоспособность
без сети (за исключением функций открытия файлов в системных приложениях
и drag-and-drop между папками в облаке — это требует доступа ОС к
сетевому каталогу, контролируемому ОС, не Программой).

2.4. **Независимость от сторонних сервисов.** Изменения в политике
операционных систем (Windows 10/11), Защитника Windows, API файловой
системы, кодека файлов и т.п. **не являются основанием** для возврата
средств или претензий к Разработчику, поскольку услуга по
предоставлению локальной лицензии выполнена Разработчиком в полном
объёме.

2.5. **Отсутствие учётных записей.** Программа не требует регистрации
и не отправляет идентификаторы Пользователя на серверы Разработчика.

5.2. **Обработка данных:** Разработчик не ведёт маркетинговый профиль
и не продаёт данные третьим лицам; обрабатывает только сведения,

5.3. **Контакт при покупке:** e-mail используется только для доставки
ключа активации и переписки по заказу. После завершения заказа
e-mail хранится на стороне Разработчика в течение срока, необходимого
для бухгалтерского учёта (5 лет для РФ, иное для иных юрисдикций).

5.4. **Автоматическая отправка диагностических отчётов.**

> **По умолчанию — ОТКЛЮЧЕНО.** В отличие от многих приложений,
> FinanceFugue **не отправляет** диагностику автоматически.

5.4.1. Если Пользователь явно нажимает «Отправить отчёт об ошибке»
в диалоге критической ошибки, Программа создаёт файл
`logs/crash_<timestamp>.log` и (опционально) открывает mailto-ссылку
на `KVF_SOFT@mail.ru` с предложением прикрепить этот файл. Передача
файла происходит только по инициативе Пользователя.

5.4.2. Передаваемый лог содержит: версию, ОС, текст ошибки, stack
trace, путь к файлу БД. Разработчик видит **только неисправную работу
Программы**, не её содержание.

5.4.3. Лог **не содержит**: данные клиентов, платежи, текст заметок,
содержимое прикреплённых файлов, пути к файлам вне папки базы данных.

5.4.4. **Никакой телеметрии, аналитики, crash-reporter Daemon.** Это
локальное приложение без фоновых процессов, отправляющих данные.
Пока Программа запущена — она работает с локальным диском, никакая
фоновая отправка не выполняется.

5.5. **HWID (идентификатор устройства) — локальный счётчик.** При
первой установке Программа может сохранить в `crm_settings.json`
хеш-идентификатор оборудования (HWID) для подсчёта числа инсталляций.
Данные **не передаются** Разработчику автоматически. Используется
только локально для функции «проверить, активирована ли лицензия на
этом ПК».

5.6. **Стороннее ПО:** сведения о лицензиях используемых библиотек
