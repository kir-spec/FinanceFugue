# Symphony Pro CRM - QML Версия

## Обзор

Это QML версия CRM приложения для управления клиентами и заказами в музыкальной индустрии. Приложение полностью переписано на Qt Quick (QML) с сохранением всей логики и функциональности оригинальной PyQt6 версии.

## Архитектура

### Backend (src/backend.py)

Бэкенд обеспечивает связь между QML и Python через:

**CRMBackend** - основной класс с сигналами:
- `currentClientChanged()` - при изменении текущего клиента
- `errorMessage(msg)` - при ошибке
- `infoMessage(msg)` - при информационном сообщении
- `successMessage(msg)` - при успешной операции

**Свойства для QML:**
- `clients` - модель списка клиентов (ClientsModel)
- `currentClient` - текущий выбранный клиент
- `statsInWork`, `statsDone`, `statsTotalAdvance`, `statsTotalDebt`, `statsTotalCash` - статистика

**Методы (вызываемые из QML):**
- Клиенты: `add_client()`, `delete_client()`, `update_client()`, `get_client_wrapper()`, `sort_clients()`
- Заказы: `add_order()`, `delete_order()`, `update_order_price()`, `update_order_status()`, `update_order_deadline()`
- Платежи: `add_payment()`, `delete_payment()`
- Файлы: `add_file()`, `delete_file()`, `open_file()`, `export_order_files()`
- Настройки: `export_json()`, `import_json()`, `is_first_run()`, `mark_first_run_completed()`

**ClientsModel** - QAbstractListModel для списка клиентов:
- Роли: NameRole, EmailRole, SocialLinkRole, NotesRole, OrdersCountRole
- Методы: `rowCount()`, `data()`, `update_clients()`

**Wrapper классы:**
- `ClientWrapper` - обертка клиента для QML
- `OrderWrapper` - обертка заказа
- `ProjectFileWrapper` - обертка файла
- `PaymentWrapper` - обертка платежа

### Frontend (qml/MainWindowWorking.qml)

Главное окно содержит:
- **Панель статистики** - 5 показателей (в работе, выполнено, авансы, долги, касса)
- **Левая панель клиентов** - ListView с клиентами, кнопка добавления, сортировка
- **Правая панель профиля** - информация о клиенте, список заказов
- **Диалоги:**
  - Добавления клиента
  - Удаления клиента
  - Добавления заказа
  - Настроек (экспорт/импорт JSON)

## Известные ограничения

Упрощенная версия (`MainWindowWorking.qml`) ограничена:
- ❌ Нет детальной информации о заказах (файлы, платежи)
- ❌ Нет контекстного меню клиента
- ❌ Нет настроек клиента (редактирование имени, email, заметок)
- ❌ Нет экспорта ZIP архивов заказов

Используйте `main_qml_full.py` для полной функциональности.

## Разработка

### Добавление новых функций

1. Добавить метод в `CRMBackend` (src/backend.py)
2. Вызвать метод из QML через `backend.method_name()`

### Пример добавления функции

**Backend:**
```python
@pyqtSlot(str, result=str)
def calculate_something(self, param: str) -> str:
    return "Результат: " + param
```

**QML:**
```qml
Button {
    text: "Вычислить"
    onClicked: {
        var result = backend.calculate_something("тест")
        console.log(result)
    }
}
```

## Troubleshooting

### Ошибка "Не удалось загрузить QML файл"
- Проверьте путь к QML файлу в скрипте
- Убедитесь, что файл существует и не содержит синтаксических ошибок

### Ошибка "module QtQuick.Dialogs is not installed"
- Установите пакет: `pip install PyQt6-QtQuick`

### Проблемы с отображением русского текста
- Убедитесь, что файлы в UTF-8 кодировке
- Используйте шрифты, поддерживающие кириллицу

## Конвертация PyQt6 Widgets в QML

Основные различия:

| PyQt6 Widgets | QML |
|----------------|------|
| QPushButton | Button |
| QLabel | Label/Text |
| QLineEdit | TextField |
| QListView | ListView + делегат |
| QComboBox | ComboBox |
| QDialog | Dialog |
| QVBoxLayout/ QHBoxLayout | ColumnLayout/ RowLayout |
| signals/slots | Connections + function |
