## Что реализовано

### 1. Бэкенд (src/backend.py)
Полный бэкенд для взаимодействия с QML (~1000 строк):

**Методы управления:**
- Клиенты: `add_client()`, `delete_client()`, `update_client()`
- Заказы: `add_order()`, `delete_order()`, `update_order_status()`, `update_order_price()`, `update_order_deadline()`
- Платежи: `add_payment()`, `delete_payment()`
- Файлы: `add_file()`, `delete_file()`, `rename_file()`, `open_file()`, `export_order_files()`
- Экспорт: `export_json()`, `import_json()`, `export_full_backup()`, `export_client_files()`, `export_client_orders()`
- Настройки: `sort_clients()`, `save_settings()`, `load_settings()`

**Свойства QML:**
- `clients` - модель списка клиентов
- `currentClient` - текущий выбранный клиент
- `statsInWork`, `statsDone`, `statsTotalAdvance`, `statsTotalDebt`, `statsTotalCash` - статистика

**Сигналы:**
- `errorMessage(msg)` - при ошибке
- `successMessage(msg)` - при успешной операции
- `infoMessage(msg)` - информационное сообщение
- `clientsChanged`, `currentClientChanged`, `statsChanged` - изменения данных

### 2. QML компоненты

#### MainWindowWorking.qml (рабочая версия)
✅ Полностью функциональная:

Создан со всеми элементами меню как в оригинале:

## Структура меню (как в оригинале)

### Главное меню
1. **➕ Новый клиент** - создание нового клиента
2. **⚙ Настройки** - диалог настроек приложения
3. **Сортировка** - выбор режима сортировки:
   - Имя (А-Я)
   - Имя (Я-А)
   - Новые заказы
   - Старые заказы
   - Срочные

### Контекстное меню клиента (ПКМ)
1. **➕ Добавить заказ** - быстрое создание заказа
2. **⚙ Настройки клиента** - редактирование данных
3. **🗑 Удалить клиента** - удаление с подтверждением

### Профиль клиента
1. **Имя клиента** - отображение имени
2. **✏️** - кнопка показа заметок
3. **➕ добавить заказ** - создание нового заказа
4. **⚙ настройки** - открытие настроек клиента
5. **Поле заметок** - редактирование заметок клиента
6. **Статистика клиента**:
   - ВСЕГО - количество заказов
   - ГОТОВО - выполненные заказы
   - АВАНС - сумма авансов
   - ВНЕСЕНО - полученные платежи
   - ДОЛГ - сумма долгов

### Диалог настроек клиента
1. **Поля редактирования**:
   - Имя
   - Email
   - Соц. сеть
   - Заметка
2. **Инструменты экспорта**:
   - 📁 Экспорт файлов (ZIP архивы)
   - 📊 Экспорт заказов (JSON)
3. **🗑️ Удалить клиента** - удаление с подтверждением

### Диалог настроек приложения
1. **База данных**:
   - Выбор места хранения
   - Импорт из папки
   - Экспорт (JSON)
   - Импорт (JSON)
   - Полный бэкап (ZIP)
   - Удалить ВСЕ файлы
   - Удалить ВСЮ базу данных
2. **Настройки**:
   - Создать копию настроек
   - Восстановить настройки
